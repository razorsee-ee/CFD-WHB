# Модель котла: все условия (версия для расчёта на выходные, ячейка 0.06 м)

Генератор `model/make_case.py`, геометрия `model/geometry.py`. OpenFOAM-12, `foamRun`, модуль `fluid`
(сжимаемый газ, гравитация), стационарно (SIMPLE). Пар увязан: 3 захода (`model/run_coupled.sh`).
Параметры — из реально сгенерированного кейса.

## 1. Область и сетка

| | |
|---|---|
| Вход | начало общего наклонного газохода (после слияния газоходов от циклонов), плоское сечение на всю ширину |
| Состав | наклонный газоход → вертикальный газоход 3.7 × 4.666 м → котёл: 2 бункера (сужаются к дну и по ширине до 1.6 м), испаритель + 4 пароперегревателя (пористые блоки 6.7 м от потолка), выходное сужение → выходной газоход, продлённый на 8 м |
| Ширина | 4.666 м (4686 по осям труб мембраны минус труба 20 мм), полная, без симметрии |
| Бункеры | заполнены золой на 10 % объёма (поверхность золы на z = 4.41 м) |
| Сетка | blockMesh, шестигранники; ячейка 0.06 м в сечении, по ширине 39 ячеек (~0.12 м); ~4.7 млн ячеек |
| Упрощения | смещение газохода вбок, сужение выхода по ширине, мелкие уступы — не учтены; высотные отметки с эскиза |

## 3. Давление
Выход **1.118 бар абс.** (вход 1.120 по DCS минус ~2 мбар). Давление на входе — результат (перепад ~50–60 Па).

## 4. Пыль (только как теплоёмкость и излучение, частицы не моделируются)
- Через пучки 40 % от 50 т/ч = 20 т/ч, частицы ~20 мкм (допущение).
- Добавка к теплоёмкости потока (~7 %); поглощение излучения пылью.

## 5. Излучение
- В объёме: P1, серый газ, поглощение **0.92 1/м** везде (газ CO₂+H₂O ~0.16 + пыль ~0.76).
- В пучках: добавка к α по газу (WSGG) и пыли: 20–28 Вт/(м²·К) (ε газа 0.13–0.15, пыли 0.10–0.11).

## 6. Стенки (мембрана: трубы 20 мм, шаг 88 мм, кипящая вода 250 °C, 40 бар)

|---|---|---|
| Зола (тепловое сопротивление) | **0.08 м²·К/Вт** (~16 мм при 0.2 Вт/(м·К)) | **0.10 м²·К/Вт** (~20 мм) |
| Металл + вода (с учётом широких проставок) | 800 Вт/(м²·К) — < 1 % сопротивления | так же |
| Температура поверхности золы | считается сама (конвекция + излучение) | так же |
| Степень черноты поверхности | 0.8 | 0.8 |

Отложения подобраны по DCS (газ ~725 °C в газоходе, 618 °C на выходе, пар 441 °C).

## 7. Пучки (пористые блоки на всю ширину, 46 рядов × шаг 100 мм, трубы 38 мм, коридорные)

| | испаритель | SH IIIb | SH IIIa | SH II | SH I |
|---|---|---|---|---|---|
| по газу | 1-й | 2-й | 3-й | 4-й | 5-й |
| трубы вдоль газа, шаг | 4, 88 мм | 12, 60/100 мм | так же | так же | так же |
| поверхность, м²/м³ | 17.8 | 18.1 | 18.1 | 18.1 | 18.1 |
| сопротивление f_x / f_y / f_z, 1/м | 7.1 / 16.7 / 0.5 | 6.4 / 17.4 / 0.5 | так же | так же | так же |
| среда | кипение 250 °C | пар (считается) | пар | пар | пар (вход 251 °C) |

- Сопротивление: Гаддис–Гнилинский (VDI), Эйлер на ряд 0.159 (SH) / 0.18 (испаритель).
- α газ: Жукаускас (коридорный) от скорости + излучение; **налёт на трубах 0.05 м²·К/Вт** (подобран по DCS);
  у пароперегревателей последовательно α пара ~670 Вт/(м²·К) (растёт с расходом пара).
  Итог при 7 м/с: ~17 Вт/(м²·К) — теплопередачу определяет налёт.
- Пар: 15.9 кг/с + впрыск 0.25 кг/с (перед SH IIIb), противоток, энтальпия по таблице водяного пара 40 бар;
  температура пара по ступеням пересчитывается между заходами (релаксация 50/50).

## 8. Расчёт
- Заход 1 — 5000 итераций, заходы 2 и 3 — по 2500 (стартуют с прошлого решения).
- Схемы: U — linearUpwind; h, k, ε — upwind (устойчиво; для потоков в пучках и бункерах достаточно).
- Релаксация: p_rgh 0.3, U/h/k/ε 0.5; излучение каждую итерацию.
- Запись: каждые 500 итераций, хранятся 2 последние; формат ascii (для картинок).

## 10. Допущения и риски

| допущение | влияние |
|---|---|
| Ровный профиль на входе, без закрутки от циклонов | **среднее**: определяет струю в газоходе → байпас |
| Пыль не несёт импульс (до бункера ~19 % массы газа) | **среднее**: может прижимать струю вниз |
| Отложения на стенках/трубах — одно число на область, подобраны по DCS | **среднее** для тепла, мало для доли байпаса |
| Стационарный RANS (k–ε) | среднее: большие вихри в бункерах в жизни качаются |
| Высоты с эскиза; сужение выхода по ширине не учтено | среднее |
| Поглощение излучения одно на весь объём | низкое (поглощено подбором золы в газоходах) |
| Излучение в пучках при заданной температуре газа | низкое (±3–5 % тепла) |
| α пара, 138 параллельных труб — оценка | низкое |
| Мембрана/проставки | < 1 % |
