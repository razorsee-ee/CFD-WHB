# Модель котла: все условия (как в серии run_batch.sh)

Генератор: `model/make_case.py`, геометрия: `model/geometry.py`. Решатель: OpenFOAM-12 `foamRun`, модуль `fluid`
(сжимаемый газ, плавучесть), стационарно (SIMPLE), 4000 итераций.

## Расчётная область

| | |
|---|---|
| Вход | начало общего наклонного газохода (после слияния газоходов от циклонов), плоское сечение на всю ширину |
| Газоходы | наклонный участок, вертикальный газоход 3.7 × 4.65 м |
| Котёл | 2 бункера (пирамидальные: к дну сужаются и по ширине до 1.6 м), 5 пучков, выходное сужение |
| Выход | выходной газоход продлён на 8 м, давление на конце |
| Ширина | 4.65 м везде (4686 по осям мембраны минус труба), полная, без симметрии |
| Упрощения | смещение газохода вбок не учтено; сужение выхода по ширине не учтено; высотные отметки — с эскиза |
| Сетка | blockMesh, шестигранники; ячейка 0.3 м (~70 тыс.) или 0.15 м (~380 тыс.); по ширине ячейка вдвое крупнее |

| | |

| Состав (ваш) | N₂ 66.96, CO₂ 14.12, H₂O 16.42, O₂ 2.50 % об. |
| Расход | 10 149 кмоль/ч = **81.0 кг/с** (227 332 Нм³/ч влажн.), задан как массовый расход на входе, профиль равномерный |
| Температура на входе | **745 °C** |
| Свойства | идеальный газ, M = 28.73; постоянные: cp = 1250 Дж/(кг·К), μ = 3.7·10⁻⁵ Па·с, Pr = 0.72 (при ~650 °C) |
| Турбулентность | k–ε, на входе интенсивность 5 %, масштаб 0.3 м |
| Гравитация | да, −9.81 м/с² по вертикали |

- Температура пара по ступеням — противоток 250 → 440 °C, прирост энтальпии поровну на ступень (задано, не рассчитано).
- α = конвекция (Жукаускас × 0.71, сценарий B) + излучение газа и пыли (16–23) ; у пароперегревателей

## Чего в модели нет

- Загрязнения стенок и труб (отсюда переохлаждение газа).
- Пыли как частиц (только её излучение в пучках и в объёме).
- Тепла, уносимого золой в бункеры.
- Теплоотдачи между паром разных ступеней (температура пара задана, а не считается).
