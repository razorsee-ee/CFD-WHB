# CFD-WHB: исходные данные и договорённости

Живой документ: что известно об аппарате, что решили, что ещё спросить. Обновлять по ходу обсуждения.

## Аппарат

- Горизонтальный котёл-утилизатор (WHB) за топкой; топливо — кокс. Размеры: десятки метров в длину, много метров в ширину; подвод газа — длинный вертикальный газоход.
- Снизу два бункера золы. Стенки котла и бункеров — мембранные, кипящая вода 250 °C (~40 бар).
- Сверху висят 5 пучков, коридорные, трубы ~38 мм: 1-й — испарительный, далее 4 пароперегревателя. Пар на входе насыщенный (из нескольких других аппаратов).
- Впрыски в пар есть, но не работают (пар и так недогрет). Вода 15 т/ч впрыскивается в топку задолго до котла — для котла это только состав газа.

## Геометрия по эскизам (до чертежей)

- Путь газа: 2 циклона → выходы (вихревые трубы) сверху → газоходы сходятся несимметрично (в плане один короткий, другой длинный наклонный) → наклонный участок вниз → длинный вертикальный газоход вниз → открывается прямо в левый бункер (пирамидальный, сужается и по ширине) → поворот вправо → испаритель над перегородкой бункеров → 4 пароперегревателя над правым бункером → выход справа.
- Пучки (пропорции по эскизу примерно верны) занимают верхнюю ~четверть высоты от потолка до низа бункеров; под пароперегревателями — открытый объём правого бункера; нижняя кромка выхода — примерно на уровне низа пучков.
- Границы (предложение): циклоны не моделировать; вход — выходы вихревых труб (массовый расход + закрутка, проверка чувствительности к закрутке); выход — продлённый патрубок, давление; низ бункеров — стенка, уровень золы — вариантами; полная ширина (несимметрия).

## Проблема

Пар плохо перегревается, температура газа на выходе слишком высокая. Подозрение — байпас газа низом, через зону бункеров. Альтернатива / второй фактор — отложения на трубах (отложения точно есть).

## Решения по модели (предварительные)

- Трубы не разрешаются: пучки — пористые зоны (анизотропное сопротивление по корреляциям для коридорных пучков + отбор тепла α·(A/V)·(T_газ − T_стенки)).
- Сетка — генератор `blockMesh` на Python из таблицы размеров; ячейка 0.3 м (отладка) → 0.15 м (~1 млн) → 0.1 м со сгущением у зазоров (3–5 млн). Симметрия по ширине — если есть.
- Модуль `fluid` (сжимаемый, с плавучестью). Сначала стационарно; не сойдётся — нестационарно с осреднением. Гравитация обязательна (оценка Ri ~ 1).
- Стенки — 250 °C, при необходимости с сопротивлением слоя отложений.
- Излучение (газ + пыль) — скорее всего нужно (P1), проверить сравнением.
- Пыль: газ сначала без пыли, затем частицы по готовому полю (доля по бункерам, удары в трубы). Теплоёмкость золы (~12–15 % теплоёмкости потока) учесть в балансе.
- Отложения и заполнение бункеров — варианты геометрии/сопротивления, не нестационарность.
- Ресурсы: ПК пользователя (8 ядер, 16 ГБ, 200–300 ГБ на HDD, путь без пробелов и кириллицы); облако (≤30 €) — только если не хватит.

## Ещё нужно от пользователя

- Геометрия (чертежи как есть).
- Температура газа на выходе: проект и факт.
- Пар: давление, расход, температура на выходе — проект и факт; схема пучков по пару (прямоток/противоток, последовательно/параллельно).
- Проектный тепловой расчёт по пучкам, если есть.
- Давление на выходе котла (для перепада).
- Плотны ли клапаны впрысков в пар.
