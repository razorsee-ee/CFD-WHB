## 3. Объект

**Горизонтальный котёл-утилизатор (WHB)** за CFB-топкой (топливо — кокс). Газ из двух циклонов (верх
топки, возврат материала в топку) → газоходы сходятся → **общий наклонный газоход** → **длинный вертикальный
газоход вниз** → открывается прямо в **левый бункер** → поворот вправо → **испаритель** (над гребнем между
бункерами) → **4 пароперегревателя** над правым бункером → сужение → выход → дальше циклон котла
(«WHB cyclone», большой перепад) → сушилка (газ охлаждают водой) → высокоэффективный циклон (большой перепад).

- Стены везде **мембранные** (трубы 20 мм, шаг 88 мм, кипящая вода 40 бар/250 °C), начиная примерно с
  места, где начинается наша модель. Бункеры тоже мембранные.
- Пучки висят с потолка, **6.7 м в газе**, коридорные, трубы 38 мм; 46 рядов поперёк с шагом 100 мм
  (4500 между осями крайних; до осей мембраны 4686). Испаритель: 4 трубы вдоль газа с шагом 88 (264 мм).
  Пароперегреватель: 12 труб вдоль (4 группы по 3, шаг 60 в группе, 100 между группами, 780 мм), петля.
- Порядок **по газу**: испаритель → **SH IIIb → SH IIIa → SH II → SH I** → выход.
  Пар — противоток: SH I → SH II → SH IIIa → SH IIIb → выход. Впрыски между всеми ступенями.
  В модели пучки названы по газу: **SH1 = SH IIIb, SH2 = SH IIIa, SH3 = SH II, SH4 = SH I**.
- На пучках пружинные молотки; какой-то налёт есть. Зола из бункеров 420–580 °C.
- Размеры (по чертежам/эскизам, см. `model/geometry.py`): газоход 3.7 × 4.666 м; потолок котла
  z = 19.81, низ пучков = верх бункеров = гребень z = 13.11; от внутреннего перегиба газохода до дна левого
  бункера 33.7 м; между центрами бункеров 10 м; промежутки между пучками 1636/1665/1474/1427, после SH4
  до сужения ~0.92 м. Высоты частично с эскиза (не уточнены).
- Картинки геометрии v0: `docs/img/geometry_v0_*.png`.

## 4. Проблемы установки (что решаем)

1. **Пар недогрет**: при 16.2 кг/с без впрысков выход 441 °C, нужно 450; при 17.5 кг/с было 418 °C.
2. **Трип установки по давлению газа в котле.** Пользователь: ожидаемая (проектная) температура газа после
   котла ~**480 °C**, а фактически ~**618 °C**. Горячий газ увеличивает перепады ниже по тракту (циклон котла,
   сушилка, высокоэффективный циклон), что поднимает давление в котле. Боятся перегородок из-за перепада.

**Текущая гипотеза (обсуждена с пользователем):** обе проблемы — следствие того, что котёл снимает ~16 МВт
вместо проектных ~32 МВт, главным образом из-за **загрязнения** (стены + трубы). Прикидка: при 618 вместо 480 °C
сопротивление циклона котла ×(891/753) ≈ +18 %; в сушилке испаряется ~+22 т/ч воды → высокоэффективный циклон
~+15 %. Перегородки (байпас) дают +3…7 % тепла SH, газ на выходе не охлаждают, добавляют ~0.4 мбар — вредны
для трипа. **Нужно от пользователя (запрошено, не получено):** давления по тракту (вход/выход котла, после
циклона котла, сушилка вход/выход, ВЭ-циклон вход/выход) и уставка трипа; есть ли дымосос; тренд газа на
выходе и пара за месяцы (с пуска/чистки); проектные данные котла; что видели при останове.

## 6. Модель (кратко; всё подробно в `docs/MODEL_SETUP.md`)

- OpenFOAM-12, `foamRun`, модуль `fluid` (сжимаемый, гравитация). blockMesh по контуру x-z, вытянут по y,
  бункеры сужаются к дну по ширине (до 1.6 м). Полная ширина. Вход — начало наклонного газохода, ровный
  профиль, массовый расход, **без закрутки**. Выход продлён на 8 м, давление 1.118 бар абс.
- Газ: состав по компонентам (`make_case.py`): N₂ 63.1, CO₂ 12.5, H₂O 21.3, O₂ 3.0 % → **89.2 кг/с**,
  M = 28.0, cp(газ) 1285, с пылью **1338** Дж/(кг·К), μ 3.7e-5, Pr 0.72 (константы; с 27.11 в `make_case_of14.py` исправлено: 1319 / 1372, μ 3.89e-5, Pr 0.76, старое — `--legacy_props`). k–ε, пристенные функции.
- Пыль: только теплоёмкость и излучение. Излучение P1, поглощение 0.92 1/м (газ 0.16 + пыль).
- Стенки: `externalTemperature` (вода 250 °C, h=800 с учётом проставок, **слой отложений** k=0.2,
  `qr qr; qrRelaxation 0.2; qrPrevious uniform 0; relaxation 0.2`), ε=0.8. Газоходы (`ductWalls`) и котёл
  (`walls`) — разные отложения. Поверхность золы в бункерах (10 % объёма) — `ash`, без теплообмена.
- Пучки — пористые cellZone: **сценарий A** (корреляции): сопротивление Гаддис–Гнилинский (Eu 0.159 SH,
  0.18 EVAP), α Жукаускас по скорости + излучение (WSGG + пыль, 20–28 Вт/(м²·К)) **через налёт R** + α пара
  (~670) последовательно. `heatTransfer` с `function1` (таблица htc(|U|)), Ta = температура пара ступени.
- **Увязка пара**: `model/run_coupled.sh` — 3 захода; после каждого `whb_summary.py` считает тепло ступеней,
  температуры пара по таблице 40 бар (впрыск перед SH IIIb), пишет `ta_next.txt`; следующий заход с
  релаксацией 50/50 и стартом с прошлого решения (`mapFields -consistent`).
- **Калиброванные отложения (м²·К/Вт): газоходы 0.08, стенки котла 0.10, налёт на трубах 0.05** — физически
  ~16/20 мм золы на стенах (k 0.2) и заметный налёт на трубах. Подобраны по DCS (см. §7).
- Сценарий B (×0.72 сопротивление, ×0.71 α из CFD куска пучка) — **ошибочно стоял по умолчанию долгое время**;
  исправлено на A. CFD куска пучка признан ненадёжным (§8).

### Решатель и устойчивость
- Грубые сетки (0.3, 0.2, 0.15 м): стационарный SIMPLE работает.
- **Сетка 0.1 м: стационарный старт из покоя расходится** на 10–15-й итерации (рывок у боковых стенок
  наклонного газохода → выход, U до 400 м/с, p_rgh −500 кПа). Не помогли: релаксация, upwind, без излучения,
  без отложений, чётный ny, старт с грубого решения, ячейки выхода. **Помог LTS** (`--lts --lts_co 5`,
  `ddtSchemes localEuler`, PIMPLE maxCo 5, Final-солверы). Проверено на 0.3 м: тот же ответ (616 °C, 8.79 МВт),
  выход на полку ~850 итераций. На 0.1 м: устойчиво, стартовые волны давления затухают (у пользователя видно
  на графике: колебания с периодом ~45 итераций, размах падает).
- `run_night.sh` по умолчанию передаёт `EXTRA="--lts --lts_co 5"`.

Правила, усвоенные в этом проекте:
- `writeInterval` должен делить `endTime` (иначе финал не пишется) — в make_case это учтено.
- `purgeWrite 2`, формат **ascii** (нужен views/summary).
- В контейнере `rm -rf $VAR` блокируется проверкой безопасности — писать `"${VAR:?}"/...` или литеральные пути.
- Не использовать `pkill -f` с шаблоном, встречающимся в своей же команде: писать `pkill -f "run_variant[s].sh"`.
- Фоновые расчёты в контейнере: Bash `run_in_background` с явным `timeout` (≤ 2 ч); команда без него уходит
  в фон с лимитом 30 мин.
- Изменения make_case во время идущей серии подхватываются следующими заходами (смешение версий) — не править
  генератор, пока у себя идёт серия, или учитывать это.
